做直流电机 PID 闭环控制，是从“会驱动电机”进入“会控制系统”的关键一步。建议你不要一开始就只盯着 PID 公式和调参，而是按“系统建模/测量 → 基础闭环 → 调参 → 工程鲁棒性”的路径推进。

---

# 1. 先明确：你要控制的到底是什么？

直流电机常见控制目标分三层，难度逐渐上升：

1. **电流（转矩）环**
   - 控制电机电流，间接控制输出转矩。
   - 需要电流采样（采样电阻、霍尔电流传感器等）。
   - 通常是最快的内环。
   - 对无刷 FOC、伺服控制尤其重要。

2. **速度环**
   - 控制 RPM / rad/s。
   - 需要编码器、霍尔传感器或测速器反馈。
   - 最适合作为你第一个 PID 项目。
   - 结构通常为：  
     `目标速度 → PID → PWM占空比 → 电机 → 编码器测速 → 反馈`

3. **位置环**
   - 控制电机转到指定角度或指定圈数。
   - 需要编码器。
   - 常见结构是串级控制：  
     `位置环（P或PID） → 速度目标 → 速度环PID → PWM`

**建议你的第一阶段目标：先做好“有编码器直流电机的速度闭环 PID”。**  
不要一开始就做位置环、电流环、FOC 或复杂的自适应控制。

---

# 2. 推荐的硬件起步组合

一个比较适合学习的配置：

- 带 AB 相增量式编码器的直流减速电机
- H 桥电机驱动模块  
  - 低功率学习：TB6612FNG、DRV8833
  - 中功率：BTS7960、VNH 系列等
  - 不太推荐 L298N 做严肃控制实验  
    因为压降大、效率低、发热明显，会干扰你的控制效果判断
- MCU：
  - STM32 很适合，定时器、编码器接口、PWM、ADC 都比较方便
  - ESP32 也可以，但实时性和定时器配置要更谨慎
- 独立电源：
  - 电机电源与 MCU 电源要注意地线共地
  - 电机电源附近加足够大的电解电容，例如 470uF～1000uF，再加小瓷片电容
- 编码器：
  - 建议至少几百线，或使用减速电机输出轴编码器
  - 分辨率太低时，低速测速会很抖

# 3. 速度闭环的核心结构

最典型的控制周期如下：

```text
每隔 Ts 秒执行一次：

1. 读取编码器计数增量 Δcount
2. 计算当前速度 speed_meas
3. 计算误差 e = speed_target - speed_meas
4. PID计算得到控制输出 u
5. 将 u 限制到 PWM 范围
6. 根据 u 的正负决定方向和占空比
7. 输出到电机驱动器
```

速度计算示例：

假设：

- 编码器每圈 `N` 个计数；
- 采样周期为 `Ts` 秒；
- 本周期编码器增量为 `Δcount`；

则：

\[
speed_{rpm} = \frac{\Delta count}{N} \times \frac{60}{T_s}
\]

例如：

- 编码器输出轴每圈 1300 计数；
- 控制周期 10ms，即 `Ts = 0.01s`；
- 一个周期内读到 65 个计数；

则：

\[
speed = \frac{65}{1300} \times \frac{60}{0.01} = 300 rpm
\]

注意：一定要弄清楚你的 `N` 到底是：

- 编码器线数 PPR；
- AB 相 1 倍频、2 倍频还是 4 倍频后的计数；
- 是否经过减速箱；
- 编码器装在电机轴还是减速箱输出轴。

这部分算错，会导致 PID 怎么调都不对。

# 4. PID 应该怎样理解？

经典 PID：

\[
u(k)=K_p e(k)+K_i \sum e(k)T_s+K_d\frac{e(k)-e(k-1)}{T_s}
\]

其中：

- `e(k)`：当前误差 = 目标值 - 测量值
- `Kp`：比例系数
- `Ki`：积分系数
- `Kd`：微分系数
- `u(k)`：控制输出，例如 PWM 占空比

直观理解：

## P：比例控制

误差大，输出就大。

- 优点：响应快、直观。
- 缺点：通常存在稳态误差。
- `Kp` 太小：电机反应慢，跟不上目标。
- `Kp` 太大：容易振荡、抖动、超调严重。

---

## I：积分控制

把过去长期存在的误差积累起来，慢慢补偿掉。

- 作用：消除稳态误差。
- 例如目标是 100rpm，实际总是只能到 95rpm，积分项会逐步增加 PWM，使速度最终接近 100rpm。
- `Ki` 太大：很容易超调、低频振荡。
- 很危险的问题：**积分饱和（Integral Windup）**。

例如电机被卡住，目标速度很高，误差持续存在，积分项越积越大；之后电机突然恢复，会因积分项过大而猛冲。

所以一定要做积分限幅或抗积分饱和。

---

## D：微分控制

看误差变化的趋势，提前“踩刹车”。

- 优点：可减小超调、改善响应。
- 缺点：对噪声非常敏感。
- 编码器测速天然可能有量化抖动，所以 D 项很容易放大噪声。

**对普通直流电机速度环来说，很多情况下 PI 就足够了。**  
建议你的顺序是：

> 先 P → 再 PI → 最后视情况加 D。

不要一开始就用 PID 全开。

---

# 5. 工程上更推荐“增量式 PID”

嵌入式电机控制中，常用增量式 PID：

\[
\Delta u(k) =
K_p[e(k)-e(k-1)]
+ K_i e(k)
+ K_d[e(k)-2e(k-1)+e(k-2)]
\]

\[
u(k) = u(k-1) + \Delta u(k)
\]

优点：

- 更适合直接控制 PWM 的增减；
- 输出限幅处理比较自然；
- 手动/自动切换时冲击较小；
- 在一些 MCU 电机控制工程里使用广泛。

一个示意代码：

```c
typedef struct
{
    float kp;
    float ki;
    float kd;

    float target;
    float feedback;

    float err;
    float err_last;
    float err_last2;

    float output;
    float output_max;
    float output_min;
} PID_t;

float PID_Incremental(PID_t *pid, float target, float feedback)
{
    pid->target = target;
    pid->feedback = feedback;

    pid->err = pid->target - pid->feedback;

    float delta_u =
        pid->kp * (pid->err - pid->err_last) +
        pid->ki * pid->err +
        pid->kd * (pid->err - 2.0f * pid->err_last + pid->err_last2);

    pid->output += delta_u;

    // 输出限幅
    if (pid->output > pid->output_max)
        pid->output = pid->output_max;
    else if (pid->output < pid->output_min)
        pid->output = pid->output_min;

    pid->err_last2 = pid->err_last;
    pid->err_last = pid->err;

    return pid->output;
}
```

但要注意：增量式 PID 不代表你可以忽略积分饱和、输出限幅和噪声问题。

# 6. 调 PID 的实用步骤

推荐你采用下面这个顺序。

## 第一步：先确认开环没问题

先不要闭环，直接固定 PWM。

例如依次给：

- 20%
- 30%
- 40%
- 50%
- 70%

观察：

- 电机转向是否正确；
- 编码器方向是否正确；
- PWM 增加时速度是否基本增加；
- 是否有明显死区；
- 不同负载下速度有何变化；
- 测速数据是否可信。

如果开环、测速、方向都没搞对，PID 调不出来。

---

## 第二步：仅使用 P 控制

设置：

```text
Ki = 0
Kd = 0
```

逐渐增加 `Kp`。

观察：

- `Kp` 很小：响应慢，目标速度达不到；
- 合适：能较快接近目标；
- 太大：速度围绕目标来回摆动，PWM 抖动明显。

找到“刚开始明显振荡之前”的较合适 P 值。

---

## 第三步：加入少量 I

在合适的 `Kp` 基础上，慢慢增大 `Ki`。

目的：

- 消除静态误差；
- 提高负载变化时的速度保持能力。

如果出现：

- 速度慢慢上下摆动；
- 超调越来越大；
- 负载变化后恢复很慢又过冲；

通常是 `Ki` 太大。

---

## 第四步：必要时再加 D

如果 PI 已经可用，但超调较大或快速变化时振荡明显，可以加一点 D。

不过对带编码器的低速直流电机，建议先考虑：

- 速度滤波；
- 合理降低 Kp；
- 合理降低 Ki；
- 提高编码器分辨率；
- 合理选择控制周期；

再决定是否加 D。

---

# 7. 控制周期怎么选？

速度环常见控制周期：

- 1ms：响应快，但编码器测速噪声可能明显，CPU 负担更大；
- 5ms：很常见；
- 10ms：非常适合入门项目；
- 20ms：也可以，但动态性能会差一些。

对于你的第一个速度闭环项目，建议：

> 先从 **10ms 控制周期（100Hz）** 开始。

之后再尝试 5ms 或 1ms，并比较：

- 测速抖动；
- 响应速度；
- PID 参数变化；
- CPU 占用；
- 控制稳定性。

重要原则：

> 控制周期变了，PID 参数往往也需要重调。  
> 不要把 10ms 下调好的 Ki、Kd 直接搬到 1ms 下使用。

# 8. 必须处理的几个工程问题

## 8.1 PWM 输出限幅

PWM 必然有范围，例如：

```c
PWM范围：-1000 ~ +1000
```

负数表示反转，正数表示正转。

任何 PID 输出都必须限幅：

```c
if (u > 1000) u = 1000;
if (u < -1000) u = -1000;
```

---

## 8.2 积分限幅 / 抗积分饱和

位置式 PID 中最容易出这个问题。

```c
integral += error * Ts;

if (integral > integral_max)
    integral = integral_max;
else if (integral < integral_min)
    integral = integral_min;
```

更进一步可以使用“条件积分”：

- 当输出已经饱和，且积分还会让输出往更饱和的方向走时，停止积分；
- 当误差方向有利于从饱和状态恢复时，再允许积分。

这比简单积分限幅更好。

---

## 8.3 电机死区补偿

很多直流电机存在死区：

- PWM 小于某个值时，电机根本不动；
- 正反转死区还可能不同。

例如 PWM 在 `0~120` 范围内不动，那么你可以做死区补偿：

```c
if (u > 0)
    pwm = deadzone + u;
else if (u < 0)
    pwm = -deadzone + u;
else
    pwm = 0;
```

但要谨慎：死区补偿会引入非线性，低速时可能造成突跳。建议先做好基础 PI，再考虑补偿。

---

## 8.4 速度测量滤波

编码器在低速下常常有测速跳变：

```text
100 rpm
100 rpm
90 rpm
110 rpm
100 rpm
```

这会导致 PID 输出抖动，尤其 D 项更明显。

可以做一阶低通滤波：

\[
v_{filter}(k) = \alpha v_{filter}(k-1)+(1-\alpha)v(k)
\]

示例：

```c
speed_filter = 0.8f * speed_filter + 0.2f * speed_raw;
```

注意：

- 滤波太强：反馈延迟大，控制变慢；
- 滤波太弱：噪声抑制不明显。

入门时可以从 `0.7 ~ 0.9` 的历史权重试起。

---

## 8.5 编码器方向与电机方向

闭环控制最经典的坑：

- 给正向 PWM；
- 电机正转；
- 但编码器计数却是负的；
- 于是控制器认为“速度越来越偏离目标”，疯狂加大输出；
- 最终电机全速冲出去。

所以第一次上闭环前一定检查：

```text
正目标速度 -> 正向PWM -> 正编码器速度
```

如果其中一个方向反了，要统一修正。

---

## 8.6 失速保护、堵转保护和安全限速

实际项目至少加：

- PWM 最大输出限制；
- 最大速度限制；
- 编码器异常检测；
- 堵转检测；
- 过流保护（如果有电流采样）；
- 控制超时保护；
- 急停逻辑。

例如：

```text
PWM已经很高，但编码器速度长期接近0
→ 可能堵转
→ 关闭PWM并报错
```

# 9. 一个建议的学习路线

## 阶段 1：控制理论基础

掌握：

- 什么是开环、闭环、负反馈；
- 一阶系统、二阶系统；
- 上升时间、超调量、调节时间、稳态误差；
- 稳定性概念；
- P、PI、PD、PID 各自的作用；
- 阶跃响应；
- 采样周期对数字控制的影响。

不必一开始死磕拉普拉斯变换、奈奎斯特图、根轨迹全部细节，但要知道它们在解决什么问题。

---

## 阶段 2：MATLAB/Simulink 或 Python 仿真

如果有条件，强烈推荐先仿真。

你可以建立一个简单电机模型：

\[
V = L\frac{di}{dt}+Ri+K_e\omega
\]

\[
J\frac{d\omega}{dt}+B\omega=K_t i-T_L
\]

即使你暂时不完全理解，也可以先观察：

- 增大 Kp 会怎样；
- 增大 Ki 会怎样；
- 负载突变会怎样；
- 加滤波会怎样；
- PWM 饱和会怎样；
- 编码器噪声会怎样。

仿真不是为了替代实物，而是为了建立直觉。

---

## 阶段 3：实物速度闭环

建议按项目拆分：

1. PWM 驱动电机；
2. 读取编码器；
3. 计算速度；
4. 串口输出速度曲线；
5. 开环 PWM-速度测试；
6. P 控制；
7. PI 控制；
8. 加速度目标切换；
9. 加/减负载测试；
10. 堵转和保护测试。

一定要把数据通过串口输出到上位机画图。  
没有曲线，光靠“听电机声音”和“肉眼看转速”调 PID，效率会很低。

可以用：

- Serial Studio
- VOFA+
- Python + matplotlib
- MATLAB
- STM32 调试串口助手等

建议至少记录：

```text
目标速度 target
实际速度 feedback
PID输出 pwm
误差 error
```

---

## 阶段 4：位置环与串级控制

速度环稳定后，再做位置控制：

```text
位置目标
  ↓
位置环 P / PID
  ↓
速度目标
  ↓
速度 PI
  ↓
PWM
  ↓
电机 + 编码器
```

通常：

- 位置环：常用 P 或 PD；
- 速度环：常用 PI；
- 电流环：常用 PI。

不要简单地“位置 PID 直接输出 PWM”，虽然能做，但串级控制通常更稳定、更符合工业控制结构。

# 12. 你可以做的第一个完整项目

建议项目名称：

> “基于 STM32 + 编码器直流减速电机的速度 PI 闭环控制系统”

最低功能要求：

- PWM 控制正反转；
- 编码器读取；
- 每 10ms 计算一次速度；
- PI 控制；
- 串口发送目标速度、实际速度、PWM；
- 上位机画曲线；
- 支持速度阶跃，例如：  
  `0 → 100rpm → 200rpm → 100rpm → 0`
- 支持手动施加负载；
- 有 PWM 限幅；
- 有积分限幅；
- 有堵转保护。

完成这个项目后，你会真正掌握：

- 定时器；
- PWM；
- 编码器；
- 采样与滤波；
- 数字 PID；
- 系统调参；
- 闭环稳定性；
- 嵌入式实时控制。

# 13. 最重要的几个经验

最后给你几条非常实用的结论：

1. **先保证测速正确，再谈 PID。**
2. **先做速度 PI，不要一开始就做位置 PID 或完整 PID。**
3. **先用 10ms 控制周期，后续再优化。**
4. **P 决定反应速度，I 消除稳态误差，D 不要滥用。**
5. **一定做 PWM 限幅和积分限幅。**
6. **一定通过串口画曲线调参。**
7. **PID 参数没有通用答案，必须基于你的电机实测。**
8. **先做出“能稳定控制”，再追求“快、准、抗扰”。**
9. **位置控制建议采用位置环 + 速度环的串级结构。**
10. **一个调得稳定的 PI，通常比一个乱加 D 的 PID 更好。**
